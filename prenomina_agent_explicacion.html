Prenomina Agent

Mapa vivo del MVP: una API recibe un Excel, un agente fuerza el uso de una herramienta y Python calcula la prenomina con reglas deterministicas.

FastAPI Puerta de entrada para salud y procesamiento: /health y /procesar-prenomina.
1 agente Agente de Prenomina usa OpenAI Agents SDK, pero no calcula importes.
1 tool calcular_prenomina_excel concentra validacion, calculo y archivo final.
0 DB No hay Postgres, SQLite ni ORM. La persistencia real son archivos Excel.

Agente

Tool principal

app/tools_prenomina.py lee Excel, detecta encabezado, normaliza columnas, valida datos, agrupa por empleado y escribe el resultado.

Contrato de salida

app/schemas.py define el JSON de respuesta: ok, mensaje, archivo, empleados procesados, total e inconsistencias.

ProcesarPrenominaResponse
Punto clave: el modelo no debe inventar calculos. El diseno actual obliga a que los numeros salgan de pandas/openpyxl, no de una respuesta generativa.

Hojas generadas

Hoja Contenido Uso operativo
Base original Copia de la primera hoja del Excel recibido. Trazabilidad: permite ver de donde salio el calculo.
Prenomina Resumen por empleado con horas, sueldo, bonos, descuentos, subtotal y total. Salida principal para revision o carga posterior.
Inconsistencias Lista de criticos y advertencias con fila, columna y mensaje. Correccion de datos antes de liberar prenomina.
Resumen Estado general, empleados procesados, total, errores y advertencias. Lectura ejecutiva del resultado.
